## التعديل والنشر

مستودع `gmloj/jaw` هو مصدر التطبيق. عدّل ملفات التطبيق في هذا المستودع وارفع التغيير إلى فرع `main` بعد التحقق. ينشر GitHub Pages محتويات الفرع تلقائيًا.

يقرأ الرابط القديم نفس ملفات الإصدار المنشور من GitHub Pages، ويحافظ على عنوانه للنسخ المثبّتة سابقًا. يبقى التخزين المحلي مرتبطًا بالرابط الذي ثُبّت منه التطبيق. تبدأ النسخة المثبّتة استخدام ملفات الإصدار الجديد عند فتحه مع اتصال بالإنترنت، وتستخدم الملفات المحفوظة عند انقطاعه.
